# Clam

Clam is a full-stack SaaS application being developed solo as a personal software engineering project.

The project is focused on building a real-world application from the ground up while exploring modern frontend development, REST API development, authentication, database design, and full-stack architecture.

## 🚧 Project Status

**Currently in development**

The project is being actively developed and features will be added incrementally as development progresses.

## 🏗️ Architecture

Clam follows a separated frontend/backend architecture:

```text
Clam
├── Frontend
│   ├── React
│   ├── TypeScript
│   └── Vite
│
└── Backend
    ├── ASP.NET Core Web API
    ├── Entity Framework Core
    └── MySQL
```

The React frontend communicates with the ASP.NET Core backend through HTTP APIs, while Entity Framework Core handles communication between the backend and MySQL database.

## 🔐 Authentication

## 🎯 Project Goals

The main goal of Clam is not simply to produce a finished application, but to gain practical experience building and structuring a full-stack system.

Areas being explored include:

* React component architecture
* TypeScript
* State management
* REST API design
* Authentication and authorization
* Database relationships
* Entity Framework Core
* API ↔ database communication
* Secure password handling
* JWT authentication
* Clean separation of frontend and backend responsibilities
* Git and version control
